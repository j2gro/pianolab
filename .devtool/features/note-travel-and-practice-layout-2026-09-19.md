# Note travel and practice layout

Give notes more distance (and thus more time) along the board before they reach the key that plays them, so the player can plan ahead.

Layout follow-ups in the same pass:

- Move status updates somewhere less intrusive than the current placement.
- Fold the Tempo bar into the pill at the top of the view.
- Shift the keyboard farther down toward the bottom of the window.
- Shorten key length so the keyboard sits lower without crowding the roll.
- After that shorten, lengthen keys by about 25% of the new size.
- Tempo slider must change playback speed on the live session, not only after Restart.
